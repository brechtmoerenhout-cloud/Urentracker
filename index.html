Welkom! Configureer sync

Om je data te synchroniseren tussen MacBook en iPhone heb je een GitHub account nodig en een persoonlijk token met Gist-toegang.

  1. Ga naar github.com en log in
  2. Klik rechtsboven op je avatar → Settings
  3. Scroll naar Developer settings (onderaan links)
  4. Klik Personal access tokens → Tokens (classic)
  5. Klik Generate new token (classic)
  6. Geef het een naam (bv. urentracker), selecteer scope gist
  7. Klik Generate token en kopieer het token
